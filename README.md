# Alpha Vidro — Site institucional

Site one-page da vidraçaria **Alpha Vidro**, feito em HTML, CSS e JavaScript puros (sem dependências).

## Destaques
- Hero com vídeo de 15s em loop infinito e efeito parallax
- Animações de entrada no scroll, contadores, cards com tilt e botões magnéticos
- Carrossel flutuante contínuo (direita → esquerda) com os projetos
- Formulário que envia o pedido de orçamento direto para o WhatsApp
- Layout responsivo e respeito a `prefers-reduced-motion`

## Rodar localmente
Abra o `index.html` no navegador ou sirva a pasta:

```bash
python -m http.server 8000
```

## Antes de publicar
Substitua os dados de contato provisórios no `index.html` e no `js/main.js`:
- `5500000000000` → número de WhatsApp com DDI + DDD
- `contato@alphavidro.com.br` → e-mail real
